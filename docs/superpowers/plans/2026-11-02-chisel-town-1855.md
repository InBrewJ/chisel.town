# Chisel Town 1855 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and package the complete Act I prototype for *Chisel Town 1855*: a decoupled Rust simulation backend streaming a 3-minute observational storyline to a Godot 4 Web client (with C++ GDExtension for swarm morphology), packaged with Docker, Nginx, `build.sh`, and `deploy.sh`.

**Architecture:** A standalone Rust service (`chisel-server`) drives the 3-minute storyline state machine and CribSheet narrative engine, broadcasting real-time JSON snapshots over WebSockets. A Godot 4 Web client (`chisel-client`) connects via WebSockets, using a C++ GDExtension module (`swarm_core`) to compute isometric lattice reconfigurations and rendering Darran Hollus's clinical observation terminal. Multi-stage Docker containers and Nginx package the system for deployment.

**Tech Stack:** Rust (`tokio`, `axum`, `serde`), Godot 4 (WASM, `gl_compatibility`), C++20 (GDExtension), Nginx, Docker, Bash.

**Spec:** [`docs/superpowers/specs/2026-11-02-chisel-town-1855-design.md`](file:///home/inbrewj/workshop/chisel.town/docs/superpowers/specs/2026-11-02-chisel-town-1855-design.md)

## Global Constraints
- Spell Darran with two As ("Darran Hollus").
- Darran is strictly an observer; the client has zero player intervention or controls during the simulation.
- Silent game for this milestone: no audio playback or audio dependencies.
- Godot rendering must use `gl_compatibility` mode for browser WebAssembly/WebGL compatibility.
- Nginx must set `Cross-Origin-Opener-Policy "same-origin"` and `Cross-Origin-Embedder-Policy "require-corp"` for Godot Web WASM.
- Workspace rule: Feel free to commit and push, but NEVER run `./deploy.sh` or `./build.sh` automatically.

## Review Focus
- **WebSocket Disconnection / Reconnection:** Client gracefully handles dropped socket connections and reconnects to a fresh session without throwing unhandled exceptions.
- **Clock Roll-Over at 180s:** Backend simulation at $t = 180s$ smoothly transitions from `ToxicCollapse` to `ColdReset` without panic or NaN metrics.
- **C++ Lattice Boundary Limits:** Swarm lattice procedural shifts do not generate negative or out-of-bounds tile coordinates.
- **Quote Engine Uniformity:** Random quote selection never panics on empty pools and properly parses all CribSheet quotes.
- **Nginx Static Asset MIME Types:** Nginx config explicitly handles `.wasm` (`application/wasm`) and `.pck` MIME types correctly.
